## 01 / About

I am a **Technical Architect** who enjoys turning complex problems into simple, reliable software. My work brings together enterprise architecture, backend engineering, cloud-native platforms and developer experience.

Outside enterprise development, I like exploring AI systems, building developer tools and experimenting with new product ideas. I care about how software works, how it evolves and how people actually use it.

```yaml
architect:
  name: Vikram Singh Rawat
  role: Technical Architect
  location: India
  focus:
    - Scalable and distributed systems
    - Platform engineering and integrations
    - AI agents and intelligent automation
    - Developer tools and product engineering
  philosophy: Keep it simple. Make it reliable. Build it to evolve.
```
